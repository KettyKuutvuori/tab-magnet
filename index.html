About the project

Problem
People keep dozens of tabs open across several windows. Regrouping them takes many small clicks and long, precise drags, one tab at a time, so most people give up and the mess stays.
Idea
Treat tabs and windows like magnets. Bring one close to another and it is pulled in; let go and they snap together. Tabs that belong to the same task attract more strongly, so related work finds its way back together with less effort.
Explores
Whether nearness can replace exact drop targets. Whether one gesture can move a whole group, with Shift-drag collecting scattered tabs. And what a browser should count as similar: the same task, the same type of page, or the same site.
Related work
Vivaldi tab stacks and the tab groups in Firefox and Chrome group tabs by dropping one onto another, through menus, or with AI suggestions. Haiku OS snaps window tabs together by proximity. Tab Magnet adds merging whole windows by nearness and gathering scattered similar tabs in a single drag.
Status
Interactive prototype. In this demo each tab's task is set by hand; a real browser would infer it from where a tab was opened, what the page is about and how the person has grouped tabs before. Next step: a comparison test against ordinary drag and drop.
